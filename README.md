# 🎓 SW융합대학 다면적 졸업인증제 RAG 챗봇

순천향대학교 SW융합대학 「2026 학과별 다면적 졸업인증제」 안내문을 기반으로 한 **졸업요건 질의응답 + 졸업 자가진단** 챗봇입니다.

| 요구사항 | 구현 |
|---|---|
| 1. 다면적졸업인증제 PDF 넣기 | `docs/2026_다면적졸업인증제_SW융합대학.pdf` + PDF의 표를 구조화한 `data/requirements.json` |
| 2. 안내받은 다른 문서도 넣기 | 순천향대 공식 홈페이지·SW중심대학사업단 안내를 정리한 `docs/순천향대_졸업인증_관련_공식안내.md` (졸업요건 구성, SW기초교육 의무, AI·SW 전공역량 졸업인증제 200점 점수표, 코딩역량 인증제, TOPCIT 혜택, 비교과 점수 프로그램, ASP·多Dream비교과센터, 항목별 출처 URL) + `docs/` 폴더에 PDF·TXT·MD·DOCX를 넣거나 앱에서 업로드하면 자동 인덱싱 |
| 3. 활동 체크 + 수업 리스트 → 졸업 충족 판정 | ① **자가진단 탭**: 체크박스/횟수 입력 + 과목 리스트 붙여넣기 ② **채팅**: 문장으로 설명하면 LLM이 `check_graduation` 도구를 호출 |

## 1. 실행 방법

### ⭐ 가장 쉬운 방법: Colab (설치 불필요)
`졸업요건_RAG_챗봇.ipynb`를 [Colab](https://colab.research.google.com)에 업로드하고 **런타임 → 모두 실행**을 누르면 마지막 셀에 챗봇 화면과 공개 링크가 나옵니다.
영구적인 웹 링크로 제출하는 방법은 `배포가이드_웹링크.md`를 참고하세요.

### 로컬 실행
```bash
pip install -r requirements.txt
cp .env.example .env          # OPENAI_API_KEY 입력 (없으면 '오프라인 모드' = 검색 결과만 표시)
streamlit run app.py          # 웹 UI
python cli.py --dept AI빅데이터 --year 22    # 터미널 버전 (/check 로 자가진단)
python tests/test_all.py      # 테스트 13개
```

> OpenAI 대신 Upstage Solar, Ollama 등 **OpenAI 호환 API**도 `.env`의 `OPENAI_BASE_URL`, `CHAT_MODEL`, `EMBED_MODEL`만 바꾸면 사용할 수 있습니다.

## 2. 시스템 구조

```
            ┌────────────── 인덱싱 (rag/ingest.py) ───────────────┐
 docs/*.pdf, *.txt, *.md, *.docx ──► 페이지/문단 청크(700자, 120자 겹침) ──┐
 data/requirements.json ─────────► 학과·학번별 '구조화 청크' ──────────────┤
                                                                     ▼
                         하이브리드 인덱스 (rag/retriever.py)
                         · 문자 n-gram TF-IDF (한국어 띄어쓰기 변형에 강함)
                         · OpenAI 임베딩 (키가 있을 때)
                         · 학과/학번 메타데이터 부스팅 + 해당 기준 청크 고정
                                                                     │
 사용자 질문 + 프로필(학과·학번) + 자가진단 결과 ──► LLM (rag/llm.py) ◄─┘
                                                    │ tool calling
                    ┌───────────────────────────────┼────────────────────┐
              search_documents              get_requirements      check_graduation
              (추가 검색)                   (항목 id·배점 조회)    (rag/checker.py 규칙 엔진)
```

### 설계 포인트 (보고서용)
1. **표 PDF 문제 해결 — 구조화 청크**
   표를 `pypdf`로 그대로 추출하면 열이 섞여서 "어느 학번의 몇 점인지" 연결이 끊깁니다.
   그래서 표를 `requirements.json`으로 옮기고, 이를 **학과×학번 1개 = 청크 1개** 형태의 자연어 문단으로 변환해 원문 청크와 함께 색인했습니다. 원문 페이지 청크도 함께 넣어 출처를 확인할 수 있습니다.
2. **계산은 LLM이 아니라 코드로**
   LLM은 덧셈이나 상한 처리(예: 학과활동 99회여도 5점만 인정)에서 실수할 수 있습니다. 판정은 결정적인 규칙 엔진(`checker.py`)이 하고, LLM은 **도구 호출로 입력을 구조화하는 일과 결과 설명**만 맡습니다.
3. **데이터 검증**: 모든 학과·학번의 항목 합이 PDF의 소계(대학공통/교과/비교과지정/비교과미지정)와 합계에 정확히 맞는지 테스트로 확인합니다.
4. **학과·학번 인식 검색**: "AI빅데이터 22학번", "컴소", "IoT" 같은 표현을 인식하면 해당 학과 청크의 점수를 높이고 다른 학과 청크는 낮춥니다. 해당 학번의 대학공통 청크와 학과 기준 청크는 항상 컨텍스트에 포함됩니다.
5. **환각 방지 프롬프트**: 문서 근거만 사용하고 [문서 n]으로 인용하게 합니다. 안내문에 없는 내용이면 多Dream비교과센터 문의를 안내합니다.
6. **API 키 없이도 동작**: 오프라인 모드에서 검색 결과와 자가진단 기능을 그대로 쓸 수 있습니다.

## 3. 판정 규칙 (requirements.json 항목 유형)

| type | 의미 | 예 |
|---|---|---|
| `course` | 과목 이수 (과목 리스트에서 자동 인식, 직접 체크도 가능) | 인간사랑, 예비창업설계 |
| `check` | 참여/이수 여부 | 졸업필수활동, 코딩역량인증제 |
| `count` | 횟수 × 회당 점수 (상한 있음) | 학과활동(회당 1점, 5점) |
| `choose` | n개 과목 중 택 | 전공영어1~4 중 택3 (+대체과목) |
| `points` | 세부 활동 점수 합산 | 비교과자율활동, 자격증/경진대회 |
| `topcit_rule` | 응시 횟수 + 수준 조건 | 메타버스&게임 TOPCIT(5) |

과목 리스트는 성적표를 그대로 붙여넣어도 됩니다. `1. 현대기본영어(2학점) A+`처럼 번호·학점·성적이 붙어 있어도 과목명만 인식합니다.

## 4. 예시 — AI·빅데이터학과 22학번 (총 95점)

* 대학공통 45: 인간사랑5, ASP(1·2학기)5, 자기주도상담5, 자기개발과 전공탐색5, 졸업필수활동15, 현대기본영어5, 봉사학습5
* 교과 10: 예비창업설계5, 중핵교양-국제사회언어영역 택1 5
* 비교과지정 21: 학과활동5(회당1), 자격증/경진대회6, 코딩역량인증제 Lv2↑5, AI·SW전공역량졸업인증제5
* 비교과미지정 19: 자율활동 공감5 / 창의4 / 글로벌10

질문 예:
- "내 학번 졸업인증 기준 전체 알려줘"
- "권장 자격증은 뭐가 있어?"
- "인간사랑, 현대기본영어, 봉사학습, 예비창업설계 들었고 학과활동 3번, SQLD 땄어. 졸업 가능해?" → 도구 호출 → 부족 항목 안내

## 5. 한계 및 주의
- 안내문에 2019학번 이전의 대학공통 세부 항목이 없어서, 2016~2018학번은 2019~2022 기준으로 계산하고 경고를 표시합니다.
- '비교과자율활동'처럼 인정 점수가 활동마다 다른 항목은 학생이 **비교과일람표에 있는 점수**를 입력해야 합니다.
- 공식 판정은 종합정보시스템 → 학부학사행정 → 졸업 → 개인별졸업진도관리 → **비교과일람표**에서 확인하세요.
